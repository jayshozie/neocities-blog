# Jayshozie's Personal Blog

This repo contains the source code of my blog at
[jayshozie.neocities.org](https://jayshozie.neocities.org).

## Prerequisites

[Zola](https://www.getzola.org)

## How to Serve?

```bash
~/ $ git clone git@github.com:jayshozie/neocities-blog
~/ $ cd neocities-blog
~/neocities-blog $ zola build # builds the website in ./public/
~/neocities-blog $ zola serve # serves the website at http://127.0.0.1:1111/
```
